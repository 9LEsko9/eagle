# eagle — логотип и иконки (дизайн-решение)

Дата: 2026-11-13. Статус: черновик на утверждение.

## Зачем
Знак для eagle — нативного плеера, который собирает музыку из разных сервисов (сейчас Яндекс Музыка и VK, дальше — другие провайдеры). Название — отсылка к городу Орлу, поэтому в знаке должен однозначно читаться **орёл** (не «птица вообще»: ранние круглоголовые эскизы читались как утка). Знак живёт рядом с логотипами провайдеров и чужими иконками, поэтому он нейтрален к ним и узнаваем на любом размере.

## Цели / не-цели / анти-цели
- **Цели:** однозначный орёл; связь с музыкой (пластинка); узнаваемость от 16 px до 1024 px; одна фирменная цветовая деталь; все платформенные форматы собираются воспроизводимо из исходников.
- **Не-цели:** фирменный шрифт для слова «eagle» (остаётся Inter); анимированный логотип; маскоты.
- **Анти-цели:** цвета или формы провайдеров (жёлтый Яндекса, синий VK); знак, который на маленьком размере превращается в кляксу или «утку»; много золота.

## Что решено
### Форма
- **Голова орла в профиль, смотрит вправо.** Признаки орла обязательны: тяжёлый клюв с крюком, линия восковицы (отделяет клюв от головы), рассечение рта, надбровье, нависающее над глазом (взгляд — клин, скошенный к клюву), плоская макушка, рваные перья на затылке (2–3 пряди).
- **Иконка приложения:** голова вырезана из светлого диска-пластинки, по диску — одна тонкая канавка.
- **Знак без диска** (голова отдельно): фавикон, аватар репозитория, пара со словом «eagle» в боковой панели.
- **Трей (T2):** силуэт диска с вырезанной головой, без канавки, одноцветный. Состояний (играет/пауза) пока нет — можно добавить позже, форма не меняется.

### Цвет
- **Иконка:** фон графит `#1A1A1D`, диск `#F2F2F4`, голова — цвет фона (вырез), **клюв — золото `#E9A23B`** (единственная золотая деталь), глаз и восковица — цвет диска, рассечение рта на клюве — цвет фона.
- **Золото — фирменный цвет eagle** (сайт, README), в интерфейсе приложения не используется: интерфейс остаётся монохромным, цвет — только из обложки.
- **Трей:** только один цвет. macOS — template image (чёрный + альфа, система перекрашивает сама); Windows/Linux — белый/чёрный под тему панели.
- **Док на десктопе (позже, в коде приложения):** та же иконка, но фон = цвет обложки текущего трека (`mix(обложка, фон темы, k)` из `eagle-context.md`), клюв всегда золотой. macOS — `NSApp.applicationIconImage`, Windows — иконка окна/панели задач. На Android и iOS иконка статичная.

## Ограничения платформ
- **iOS:** 1024 px, без прозрачности, маску накладывает система.
- **macOS:** проверить актуальные требования Apple к иконкам приложения (формат Icon Composer / `.icon`, слои) на момент сборки; запасной путь — `.icns`.
- **Android:** адаптивная иконка 108 dp — передний план (голова + диск), фон (графит), монохромный слой для тематических иконок (тот же силуэт, что у трея). Диск целиком внутри безопасной зоны 66 dp.
- **Windows:** `.ico` с размерами 16, 20, 24, 32, 40, 48, 64, 256.
- **Трей macOS:** 18 pt (@1x 18 px, @2x 36 px), template. **Windows:** 16/20/24/32 px.
- **Мелкие размеры (≤ 32 px)** — отдельно подогнанная геометрия: меньше прядей, крупнее глаз, без восковицы, канавки и рассечения рта (они пропадают). Детали тоньше 1 px на целевом размере убираются.

## Подходы
1. **Чистая перерисовка по сетке в SVG + сборка размеров утилитой на Rust (`resvg`)** — **выбрано.** Воспроизводимо, лежит в репозитории, остаётся на Rust; мелкие размеры подгоняются отдельными исходниками. Минус — правки через код или SVG-редактор.
2. Визуальный холст (тип Design) с экспортом PNG/PDF — удобно двигать на глаз, но платформенные форматы всё равно собирать отдельно. Не выбрано.
3. Выгрузить эскизы как есть — быстро, но кривые от руки заметны на 1024 px. Не выбрано.

## Что получается (раскладка)
```
assets/brand/
  src/            # исходники SVG (источник правды)
    mark.svg            # голова без диска
    icon.svg            # иконка: фон + диск + голова + золотой клюв
    icon-small.svg      # иконка для ≤ 32 px
    icon-fg.svg / icon-bg.svg / icon-mono.svg   # слои Android
    tray.svg            # T2, крупные размеры
    tray-small.svg      # T2, 16–18 px
  out/            # сгенерировано, в git не обязательно
tools/brand/      # крейт-утилита: resvg → PNG всех размеров, упаковка .ico/.icns, ресурсы Android/iOS
```
Цвета в SVG задаются так, чтобы утилита могла подменить фон (нужно для будущей иконки в доке в цвет обложки).
