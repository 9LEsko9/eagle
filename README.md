# Eagle

Eagle — музыкальный плеер на Rust с настольным интерфейсом и CLI. Проект находится в бета-стадии: отдельные сценарии и платформы ещё требуют проверки на реальных устройствах и аккаунтах.

## Возможности

- Настольный плеер: поиск, медиатека, очередь, плейлисты, история и управление воспроизведением.
- **Яндекс Музыка:** вход по токену, поиск и воспроизведение, лайки, плейлисты и сохранение доступных треков для прослушивания без сети. Возможности зависят от доступа аккаунта; поддерживаются MP3, но не заявлена поддержка lossless и шифрованных потоков.
- **SoundCloud:** гостевой поиск и воспроизведение доступных публичных треков; можно подключить собственный аккаунт для чтения понравившихся треков. Интеграция экспериментальная и использует недокументированный интерфейс сайта. Лайки на сервере не изменяются, плейлисты и загрузка для офлайна не поддерживаются. Воспроизведение с реальным аккаунтом ещё не проверено. [Ограничения SoundCloud и HLS](docs/soundcloud.md).
- **CLI:** воспроизведение локальных файлов, HTTP-адресов и доступных треков провайдеров. HLS можно воспроизводить, но нельзя сохранить через `--save` или `--download-only`. [Команды и хранилище](docs/cli.md).

## Установка

Архивы desktop и CLI публикуются в [GitHub Releases](https://github.com/9LEsko9/eagle/releases) для Windows x86-64, Linux x86-64 и macOS на Apple Silicon и Intel. Распакуйте архив и запустите `eagle-desktop` (в Windows — `eagle-desktop.exe`); на macOS откройте `Eagle.app`.

Windows-сборка не подписана. Приложение macOS подписано ad-hoc, без нотариального заверения Apple, поэтому система может запросить разрешение на запуск. Linux-сборке нужна совместимая система с glibc 2.35 или новее и системные библиотеки. Подробности и зависимости — в [инструкции по релизам](docs/releases.md).

## Сборка из исходников

Нужен Rust 1.92 или новее; для Linux также установите [зависимости разработки](docs/development.md).

```sh
cargo run -p eagle-desktop
cargo run -p eagle-cli -- play song.flac
cargo run -p eagle-cli -- yandex login
cargo run -p eagle-cli -- play yandex:123
```

Для Яндекс Музыки нужен токен собственного аккаунта; инструкции по получению и безопасному вводу приведены в [документации CLI](docs/cli.md). Токены хранятся в системном хранилище секретов.
